# CtrlAccess
Sistema de monitoramento integrado à API da Control iD, projetado para automatizar o ciclo de abertura e trancamento de acessos. Através de uma interface intuitiva, o usuário agenda horários programados, permitindo que o sistema gerencie remotamente os bloqueios, garantindo segurança operacional e autonomia na gestão de fluxos.
